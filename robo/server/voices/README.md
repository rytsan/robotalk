# Voices

Esta pasta guarda os arquivos da voz do Piper.

É necessário baixar estes dois arquivos:

- `pt_BR-faber-medium.onnx`
- `pt_BR-faber-medium.onnx.json`

## Download com `wget`

```bash
wget -O pt_BR-faber-medium.onnx "https://huggingface.co/rhasspy/piper-voices/resolve/main/pt/pt_BR/faber/medium/pt_BR-faber-medium.onnx?download=true"
wget -O pt_BR-faber-medium.onnx.json "https://huggingface.co/rhasspy/piper-voices/resolve/main/pt/pt_BR/faber/medium/pt_BR-faber-medium.onnx.json?download=true"
```

Depois de baixar, coloque os dois arquivos nesta pasta.
